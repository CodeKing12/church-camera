Trust the laptop

One time, on the camera phone only. Three minutes.

Download the certificate

Tap Allow when iOS asks about a configuration profile.

  1. Tap the button above. iOS saves it and says a profile was downloaded.
  2. Open Settings. Near the top: Profile Downloaded → tap it → Install → enter your passcode → Install again.
  3. Still in Settings: General → About → scroll to the bottom → Certificate Trust Settings → switch ON next to Church Camera Local CA.
Step 3 is the one everybody misses. Installing the profile on its own does nothing at all — iOS keeps the certificate but will not trust it until that switch is on, and the camera app then fails exactly the same silent way as if you had never installed it.

Then check it worked

Open Church Camera → SET → Test. Green means the phone reached the laptop and trusted it. Red still means one of the two is wrong — and the laptop has to be switched on and on the same wifi for the test to mean anything.

If tapping the button only downloads a file

Some iOS versions will not start the install from a download. Open the Files app → Downloads → tap church-camera-ca.crt, then carry on from step 2.

If it says the profile is not signed

That is expected and fine. It is a certificate we made ourselves, on the laptop, for the laptop — there is no outside authority to sign it, and none is wanted.

This file is only the public half. It lets this phone recognise the church laptop; it grants nothing to anyone else and carries no secret. The private half never leaves the laptop. Install it on the camera phone and nowhere else, and if the laptop is ever replaced or lost, remove it under Settings → General → VPN & Device Management.
